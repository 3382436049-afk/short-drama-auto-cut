# 抖音 / 红果 竖屏短剧：节奏与字幕规范

不是审美偏好，是完播率和付费转化的硬约束。

## 单集结构（60–90 秒）

| 位置 | 必须发生什么 | 常见错误 |
|---|---|---|
| 0–3 秒 | 接住上集钩子，人物已在情绪里 | 黑场、logo、片头、"第X集"字卡 |
| 3–15 秒 | 一个具体动作（扔东西/抢手机/掀床垫） | 只靠台词交代 |
| 中段 | 一次反转或笑点 | 平铺直叙 |
| 最后 3 秒 | 台词半句被截断 / 悬念动作 | 把动作做完再切 |

- 单集 <60 秒显得没内容；>90 秒完播率断崖（大结局可到 135 秒）。
- 每集 ≤2 个花字，爆点用（"限定版！""滚出去"），满屏花字=廉价。

## 卡点三招（抖音/红果通用）

1. **抽帧静音**：爆点前 0.2 秒把音乐**硬切**掉，不是淡出。
2. **Drop 重音**：关键动作那一帧叠一记低频 boom（音效，不是音乐）。
3. **集尾空拍**：最后 3–5 秒撤光音乐，只留环境音 + 心跳。

## 字幕（竖屏唯一正确姿势）

| 项 | 值 |
|---|---|
| 字体 | 思源黑体 Bold / 阿里巴巴普惠体 Bold |
| 字号 | 画面宽的 5.6%（1080 宽 → 约 60px） |
| 颜色 | 白字 + 4px 黑描边 + 1px 阴影；关键词 #FFD400 黄 |
| 位置 | 距底 380–420px（VTT `line:82%`），居中，别压脸 |
| 行长 | 单行 ≤14 字，最多 2 行 |
| 标点 | 句末不加句号；"……"保留；数字用阿拉伯数字 |
| 断句 | 跟气口，不跟语法 |

## 导出（竖屏投放）

- 1080×1920、25 或 30fps、H.264、8–10 Mbps、AAC 192kbps
- 响度：人声为主，整体 -14 LUFS 左右；音乐只在"听得见"的量级
- 命名：`剧名_EP01_竖屏_1080x1920.mp4`

## 平台侧注意

- 片头片尾各留 0.3 秒余量，避免被平台裁切
- 不要放二维码/水印/联系方式（限流）
- 音乐必须在平台商用曲库或自有授权内，否则可能下架
